# 🎬 MoviesApp

A movie management web application that allows users to browse movies, view their ratings, and manage a movie collection through a simple and user-friendly interface.

## 🌐 Live Demo

[View MoviesApp](https://movie-lovat-psi.vercel.app/movie)
[LinkedIN Demo MoviesApp](https://lnkd.in/p/dwfCmkeJ)

## ✨ Features

- 🎥 **Movies List:** Display movies with their posters, titles, and ratings.
- ➕ **Add Movies:** Add new movies to the collection.
- ✏️ **Edit Movies:** Update existing movie information.
- 🗑️ **Delete Movies:** Remove movies from the collection.
- ⭐ **Movie Ratings:** Display movie ratings out of 10.
- 🧭 **Navigation:** Navigate between Home, Movies, About, Login, and Signup pages.
- 📱 **Responsive UI:** A clean, organized layout designed for a better browsing experience.

## 🛠️ Technologies Used

- **Frontend:** Next.js , React.js
- **Styling:** Bootstrap
- **API Integration:** Json data
- **Deployment:** Vercel
